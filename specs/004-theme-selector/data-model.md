# Data Model: Theme Selector

## Theme Mode

The user's selected mode; exactly one of:

- `Light`
- `Dark`
- `System`

The API persists and returns the canonical casing above. The API rejects any other value. The browser validates returned data against the same three-value set.

## User Theme Preference

One optional record per signed-in Identity user.

| Field | Type | Constraints and meaning |
|---|---|---|
| `UserId` | String | Required; primary key and foreign key to `AspNetUsers.Id`; taken from the authenticated principal, never from request data. |
| `Mode` | Theme Mode | Required; one of Light, Dark, or System. |
| `UpdatedAtUtc` | Date/time with offset | Required; server-generated UTC time for the most recent successful save. |

### Relationships

- `ApplicationUser` has zero or one `UserThemePreference`.
- Deleting the Identity user cascades to its preference.
- No preference row means the effective selected mode is `Light`; reading the default does not require creating a row.

### Validation and Persistence Rules

- Only the exact three supported mode names are accepted.
- A preference is read and written only for the authenticated user's ID.
- A successful save replaces that user's previous mode. The server's last successfully committed write is authoritative across devices.
- A failed save does not prevent the chosen mode from applying during the current page visit. If no server preference is available on a later visit, start in Light mode.
- `UpdatedAtUtc` is generated by the server, not supplied by the client.

## Effective Appearance

The effective appearance is derived and is not persisted separately.

| Selected mode | Effective appearance |
|---|---|
| Light | Light, independent of OS changes |
| Dark | Dark, independent of OS changes |
| System | Dark when the OS currently requests dark; otherwise Light, including when that preference is unavailable |

When System is selected, OS color-scheme changes update the effective appearance without changing the saved mode. Switching to Light or Dark stops OS changes from affecting the effective appearance.
